# Duplicate File Finder – Python Day 163

## Description
A Python utility that scans folders and identifies duplicate files by comparing their SHA-256 hashes.

## Features
- Scan folders and subfolders
- Compare file contents using SHA-256
- Identify groups of duplicate files
- Handle inaccessible files
- Generate a duplicate file report
- Does not delete or modify files

## Technologies
- Python
- os Module
- hashlib Module
- collections Module

## File
- `duplicate_finder.py`

## How to Run
```bash
python duplicate_finder.py
```

## Concepts Used
File Handling, Directory Traversal, Hashing, Dictionaries, Binary File Reading and Exception Handling.
